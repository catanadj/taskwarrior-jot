# Jot Documentation

Jot is a practical notebook for Taskwarrior. Use it when a task needs more
than a status, due date, and description.

## Start Here

- [Getting started](getting-started.md): the first commands and a normal day
- [Notes and resources](notes.md): task, chain, project notes, links, and files
- [Progress and time](progress-and-time.md): track progress and time spent
- [Terminal UI](tui.md): browse and edit without memorising commands
- [Configuration](configuration.md): templates, paths, color, and integrations
- [Compatibility](compatibility.md): supported environments and stability promises
- [Nautical integration](nautical.md): how Jot complements recurring tasks
- [Command reference](reference.md): concise command and option reference

## Design Principle

Jot does not impose a productivity method. Notes, progress tracks, time logs,
and project context are available when useful and stay out of the way when
they are not.
